CupBack docs

Pay for a cup. Return it. Get your money back.

CupBack uses Bitcoin Cash. Deposits are real BCH.

Pay and return a cup

  1. Scan the event’s pickup QR code and check the deposit amount.
  2. Connect your wallet, select Pay deposit, and approve in your wallet.
  3. Save the receipt. Show it with your cup at the return booth.
  4. Open the receipt again to check the refund. Use Refresh if the status hasn’t updated.

After the event’s self-refund time, the original payer can recover any deposit that hasn’t been refunded.

Approve a return

  1. Open Return booth. Scan the guest’s receipt or paste its link.
  2. Check the cup and confirm the receipt says Ready to return.
  3. Connect the event’s booth wallet. Select Approve refund, then approve in your wallet.
  4. Check the result and use Scan next receipt for the next return.

The guest receives the full deposit. The booth wallet covers the network fee.

Set up an event

  1. Open Set up event. Enter the event name, deposit amount, and when self-refunds begin.
  2. Paste the booth wallet’s first receive address. Add an organizer wallet only if it should also approve refunds.
  3. Create the pickup QR code and display it where guests pick up cups.

Save the pickup link to share it across devices. The saved events list lives in the browser that created the event.

Connect a wallet

Choose Cashonize in the wallet picker, then select Open Cashonize. Check that the right wallet is active and return to CupBack once it connects.

If the handoff doesn’t connect, choose Connect manually. Copy the link, paste it into Connection URI in Cashonize’s Connect tab, and select Connect New dApp.

To pair from another device, scan the connection QR code from Cashonize or another WizardConnect wallet. Keep CupBack open while pairing.

At the booth, use Scan next receipt to keep the wallet connected in the same CupBack tab. The header shows the connected wallet’s shortened address.
